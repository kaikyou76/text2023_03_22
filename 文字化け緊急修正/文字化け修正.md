---

## ✅ 【確実版】eecCommon.js を Shift_JIS に戻す手順（VSCode）

### 🔹 ① ファイルを開く

VSCode で `/js/eecCommon.js` を開きます。

---

### 🔹 ② 文字化けを一時的に回避して正しい文字を読み込む

もし今、画面上に「文字化け」が見えている場合、
それは **UTF-8 ファイルを Shift_JIS として誤読している状態** です。

一旦、**正しく UTF-8 として読み直す**必要があります：

1. 右下ステータスバーにある「文字コード」（例：`Shift JIS` や `UTF-8` と表示）をクリック
2. 「Reopen with Encoding（エンコーディングで再読み込み）」を選択
3. 「UTF-8」を選択
4. ファイルが正しく読めた（日本語が復活した）ことを確認

---

### 🔹 ③ 正常に見える状態で「Shift_JIS」に変換して保存

1. 再び右下の「UTF-8」をクリック
2. 「Save with Encoding（エンコーディングで保存）」を選択
3. 「Japanese (Shift_JIS)」を選択
4. 上書き保存（Ctrl + S）

これで、ファイルが Shift_JIS として正しく再保存されます。
（内部的には、UTF-8 → Shift_JIS に変換した状態）

---

### 🔹 ④ GitLab への再コミット

```bash
git add js/eecCommon.js
git commit -m "文字コードをUTF-8からShift_JISに統一"
git push
```

※このとき、Git の差分には大量の文字化け行が**再び消えて正常な文字列になる**はずです。

---

### 🔹 ⑤ ブラウザで再確認

1. Apache／Tomcat を再起動（キャッシュをクリア）
2. ブラウザで Ctrl + F5 で再読み込み
3. コンソールエラー「Invalid or unexpected token」が消えていれば成功です ✅

---

## 💡 参考：再発防止策（チーム開発向け）

もし GitLab に複数人でコミットしている環境なら、次の設定を入れておくと安心です。

### `.gitattributes` に追加：

```gitattributes
*.js text working-tree-encoding=Shift_JIS
*.html text working-tree-encoding=Shift_JIS
*.css text working-tree-encoding=Shift_JIS
```

これで、
ローカル環境では Shift_JIS、Git 内部では UTF-8 で保持され、
将来的に UTF-8 統一したくなったときもスムーズに移行できます。
